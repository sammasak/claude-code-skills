# Token optimization via clarity, not deletion

When reducing skill token counts, focus on removing redundancy and tightening language in descriptions and examples rather than cutting features. The session achieved 59.5% token reduction (11K→4.6K words) while improving eval solve rate from 33% to 47%, proving that clarity and specificity compress better than deletion. Strategy: identify boilerplate explanations that appear across multiple skills, consolidate trigger examples to the most common cases, and use precise language to replace verbose patterns.
